# La Cassita de GL

A cozy beach-house site for GL.

## What's in this repo

This is a static-site deployment of **La Cassita de GL**, previously living inside the larger Runway redesign output and deployed as a separate Vercel project (`gl-cassita-site`).

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy

```bash
vercel --prod
```

## Asset sources

- Static build output: `02_DATA/kimi-agent-outputs/Kimi_Agent_Runway_App_Redesign/gl-cassita-site`
- Images: pulled from the existing Vercel deployment
